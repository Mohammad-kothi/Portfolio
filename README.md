# Mohammad Kothi — Portfolio

Personal portfolio of Mohammad Kothi, a first-year B.Tech Computer Science student at Newton School of Technology.

**The current site is in [`web/`](web/)**: a Next.js 16 + Tailwind CSS 4 + Framer Motion app with a dark, editorial
design, scroll animations, and a "cursors building the page" intro.

| Folder | What it is |
|---|---|
| [`web/`](web/) | The portfolio (current version). See [`web/README.md`](web/README.md) for how to run, edit and deploy it. |
| `index.html`, `style.css`, `script.js`, `images/` | The first version: a plain HTML/CSS/JS page, kept for reference. |

## Run it

```bash
cd web
npm install
npm run dev
```

Then open <http://localhost:3000>.

## What's on it

- **Projects**: Tokenizer Lab and Suiii Playground (live AI web apps), the Kothi Steel Ltd client site,
  the Ridgeline Roofing bounty template, the Business OS concept, and college lab work
- **Case study**: Kothi Steel Ltd
- **Skills**, **education & experience timeline**, and **contact**

All the text and links come from one file: [`web/src/content/portfolio.ts`](web/src/content/portfolio.ts).
